## One arm bandit 
Это простая реализация игрового автомата(однорукого бандита) на C++.
Репозиторий содержит исходный код, хедер файл и Dockerfile для сборки и запуска приложения в контейнере

## Архитектура:
- **Reel** — ,барабаны игрового автомата
- **PayLine** — схемы выигрышных линиий
- **Paytable** — правила выплат
- **Evaluator** — считает выплаты
- **SlotMachine** — координирует игровую логику
